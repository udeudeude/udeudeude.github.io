A free, local-first tool for Apple Health exports. Explore measurements, save CSV data, and print a stack of Apple Watch ECGs at once.

01 / LOAD

Choose your Apple Health export

In Health, tap your profile → Export All Health Data → Save to Files. Choose the resulting ZIP here. You can also use an extracted export.xml, or an individual ECG CSV.

The file stays in this browser. No account, subscriptions, servers, or analytics.

02 / PRINT

Apple Watch ECGs, together

Each ECG CSV in the archive can become a waveform page. Choose recordings, then print or save a PDF from the iPhone share/print sheet.

0 selected

Waveforms are reconstructed from the exported CSV. They are not Apple's original clinical PDF and should not replace it for diagnostic use. ECG print scale is marked only when the data includes a recognizable time/voltage unit.

What this version supports

Included
Standard Apple Health export ZIPs (including ZIP64), measurements, categories, workouts, activity summaries, correlations, ECG CSV waveform files, date filters and print layouts. XML is parsed a chunk at a time.

Not yet included
Direct HealthKit access (requires a native iOS app), clinical-record PDFs, route maps, metadata nested inside XML records, or automatic recurring exports.

Files are read in the browser only. Nothing is transmitted, indexed or stored by this page. Refreshing clears the session.
