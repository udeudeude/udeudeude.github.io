Independent Stereo Laboratory

Experimental, independently implemented browser renderer. Upload a photograph and, ideally, a corresponding grayscale depth map. Everything runs locally in this browser; images are not uploaded. This is not yet the replacement Anaglyph & Friends application.

Choose a photograph to begin.

Experimental limitations: maximum working width 800 px; nearest-pixel splatting with explicit depth-order resolution; horizontal gap interpolation, not true hidden-surface reconstruction. The optional synthetic depth is for testing the renderer, not AI depth estimation. Original input photos remain yours.
