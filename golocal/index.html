Browser / mapping experiment

Asheville GoLocal Card + Google Maps

An experiment in making the Go Local directory easier to use alongside an everyday map.

The idea

It is useful to know which independent Asheville businesses take part in the Go Local Card program while planning a route, choosing nearby shops, or exploring a neighborhood. This project brings that information into a Google Maps workflow rather than making you switch back and forth between separate directories.

Current form

The experiment has been distributed as a Mac/browser utility, including a Brave-compatible package. It is not currently published here as a maintained download, and this page is not a live interactive map. A public release link can be added when the package is ready for that role.

Independent experiment. This is not an official Go Local Asheville product or a substitute for its current business listings. Go Local participation and offers may change; check the official directory for up-to-date details.
