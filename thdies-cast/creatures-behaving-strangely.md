# Creatures Behaving Strangely

Twenty independent encounters involving creatures with curious habits. Rather than prescribing an enemy, a reward, or a solution, each offers an observation that the group may choose to investigate.

HOW TO USE THIS EPISODE
Seek to a random point during the encounters. Ignore any scene already in progress. The next complete encounter begins after a quiet chime. If you reach the closing remarks, return to the first scene after the introduction.

There are twenty encounters of equal playback duration, so each is equally likely if you seek uniformly across the encounter portion. Hand-operated scrubbing is not guaranteed to be uniform. Printed titles and numbers are not spoken. A final closing remark is not an encounter.

Narrated by Brother Rubicon using Kokoro Lewis with the producer-selected Saved 02 treatment. Original encounter prose; suitable for many tabletop games.
