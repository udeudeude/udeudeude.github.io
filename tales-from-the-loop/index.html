01

Make it yours. Keep the edit link.

First copy and save

  1. Open the public template. In its top bar, choose Source → Clone to New.
  2. In Brew Editor, replace a bracketed field with your own text. In Properties (ⓘ), give the brew a name.
  3. Click Save Now in the top bar. Wait for the saved status.
  4. Bookmark the resulting /edit/ address. This is the link you return to when you want to change your document.

Then edit and share

After the first save, edits save automatically. Check the saved status before closing the tab.

Use Share → View to open the public /share/ page. Give that link to readers.

Get PDF makes a printable version. Keep your editable brew as well.

Treat your edit URL as private: it can grant editing access. Keep a source backup too.

Save Now disabled? A newly cloned copy may need a change first. Replace a field or rename it, then check the top bar again. If it already says saved, use the edit address in your browser.

Copy complete page patterns or individual blocks. Keep the examples you need and remove the rest.

Page numbers update automatically. Page breaks and text overflow need your attention. This is a formatting toolkit; use the RPG’s rules for play.

03

Your information. The same visual system.

Replace the content

Write in Brew Editor. Replace the [bracketed fields] with your story, stats, names, and credits. The Style Editor controls the shared appearance.

For a callout or reference card, copy the whole block from an example, including its opening {{ and matching closing }}. Change the words inside it.

{{callout
### A clue worth keeping
[Your own information here.]
}}

Add another page

Copy the complete continuation page, from its rail through its footer. Put this on its own line between sheets:

\page

Keep both loopColumn blocks inside their loopGrid. Put a full-width section before or after the grid.

Check each sheet in the preview. Long text stays on that sheet; shorten it or move some to the next page.

Add images when you have them

On the image example page, replace the placeholder inside an imageSlot with ![Description](PUBLIC_IMAGE_URL). Use a direct, publicly accessible image URL. Keep the figure and caption wrappers, and add an artist credit. The default frame fits the whole image; imageCover crops it to fill the frame.

Restore the template from these files
  1. Open a new Homebrewery brew and use the V3 renderer in Properties.
  2. Paste tftl-toolkit-content.md into Brew Editor.
  3. Paste tftl-toolkit-style.css into Style Editor.
  4. Give the brew a name, save it, and bookmark the edit address.

These downloads are the original eight-page toolkit. To back up your customized brew, also copy your own Brew Editor content and Style Editor CSS.

06

When something looks wrong.

I can read it, but I can’t edit it.

You may be on the public share page. Open your bookmarked /edit/ URL. To start your own copy of the public template, choose Source → Clone to New.

Text runs off the page or overlaps the footer.

Homebrewery does not automatically flow this template’s text onto another sheet. Shorten the section or copy a continuation page and move some content there. Check for a long URL, unbroken text, or a missing closing }} if a block extends sideways.

The content is there, but the styling is missing.

Use V3 and check the Style Editor. If you restored from files, paste the CSS as well as the Markdown. Cloning the public template is the simplest starting point.

My image doesn’t appear.

Try opening its URL directly in a new tab. It should display the image itself without a sign-in. A local file path or a link to a gallery page will not work as the image URL.
