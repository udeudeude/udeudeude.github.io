TALES FROM THE LOOP — HOMEBREWERY FORMATTING TOOLKIT v4

Public template: https://homebrewery.naturalcrit.com/share/1mDaK9DdiNQZ

EASIEST START
Open the public template and choose Source > Clone to New.

USING THIS BACKUP
1. Open a blank Homebrewery brew with the V3 renderer.
2. Paste tftl-toolkit-content.md into Brew Editor.
3. Paste tftl-toolkit-style.css into Style Editor.
4. Rename and save your brew.

Copy example pages or individual components and replace bracketed fields.
Keep container braces intact. Separate pages with a backslash followed by
page on its own line. Page numbering is automatic; text pagination is manual.
The image frames contain placeholders. Insert public image URLs when ready.
No official artwork or logos are included.

Ten example pages, including a worn SVG clue-flow map, title-page template, and eight fictional organization logos.
Poppins, Crimson Text and Special Elite web fonts are hosted at
https://udeudeude.github.io/tales-from-the-loop/fonts/
A network connection is needed to load the hosted fonts; fallback fonts remain available.
The included fonts folder contains offline font files and license notices.
Design reference: Free League Workshop Tales from the Loop design templates:
https://www.drivethrurpg.com/en/product/295319/tales-from-the-loop-free-league-workshop-design-templates
Our HTML/CSS graphics are independently made; the official graphical assets are not bundled.

SVG ASSETS
The assets folder contains original frames, arrows, white sidebar flecks,
gray stationery texture, and fictional organization logos.
The stylesheet references the hosted versions at
https://udeudeude.github.io/tales-from-the-loop/assets/
For independent hosting, replace that base URL with your own public asset location.
Paper boxes use Nordhamn Energi by default; add a brand class from page 10
or use noBrand to remove the logo. Copy page 09 to the front for a cover.
