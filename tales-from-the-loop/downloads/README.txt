TALES FROM THE LOOP — MULTIPAGE FORMATTING TOOLKIT

Public template: https://homebrewery.naturalcrit.com/share/1mDaK9DdiNQZ

EASIEST START
Open the public template and choose Source > Clone to New.

USING THIS BACKUP
1. Open a blank Homebrewery brew with the V3 renderer.
2. Paste tftl-toolkit-content.md into Brew Editor.
3. Paste tftl-toolkit-style.css into Style Editor.
4. Rename and save your brew.

Copy example pages or individual components and replace bracketed fields.
Keep container braces intact. Separate pages with a backslash followed by
page on its own line. Page numbering is automatic; text pagination is manual.
The image frames contain placeholders. Insert public image URLs when ready.
No official artwork or logos are included.
